# estacao-meteorologica-ESP32
Sistema meteorológico IoT com ESP32 (Heltec WiFi LoRa 32 V2) e sensores BMP180, HTU21D e LDR. Monitora temperatura, umidade, pressão atmosférica e luminosidade em tempo real, com dashboard web interativo. Projeto realizado com a intenção de ajudar locais afastados, como zonas rurais que não tem acesso a sistemas meteorológicos em sua area.
